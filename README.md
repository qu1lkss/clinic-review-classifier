# Оценка клиники по тексту отзыва

Можно ли по отзыву понять, поставил автор 1–2 звезды или 4–5? На отзывах с Яндекс Карт сравниваем логистическую регрессию и нейросеть на PyTorch. [Ноутбук с обучением и разбором ошибок](clinic_reviews.ipynb)

| Модель | Macro-F1 | Precision для 1–2 звёзд | Recall для 1–2 звёзд |
|---|---:|---:|---:|
| TF-IDF + логистическая регрессия | 0,8911 | 0,7366 | **0,9198** |
| Нейросеть с EmbeddingBag | **0,9131** | **0,8101** | 0,9011 |

В тесте было 374 отзыва с 1–2 звёздами. Логистическая регрессия верно отнесла к этому классу 344 отзыва, нейросеть — 337. Нейросеть ошибочно отнесла к этому же классу 79 отзывов с 4–5 звёздами, логистическая регрессия — 123.

## Пример прогноза

```console
$ python predict.py "Записался на десять утра, в кабинет попал только в одиннадцать"
Прогноз оценки: низкая
```

Скрипт загружает обученную модель и словарь из папки `artifacts/`.

## Данные

В Yandex Geo Reviews Dataset 2023 нашлось 17 757 отзывов по девяти рубрикам клиник, поликлиник и стоматологий. После очистки и исключения оценок на три звезды осталось 17 143 отзыва. [Описание набора у Яндекса](https://github.com/yandex/geo-reviews-dataset-2023) · [Версия Parquet на Hugging Face](https://huggingface.co/datasets/d0rj/geo-reviews-dataset-2023/tree/02366bc66bd43aa69e707747487ec8f3c22cac84)

Клиники разделены по названию и адресу (seed 42). Все отзывы одной клиники попали в одну часть: 12 029 отзывов в обучении, 2 564 в валидации и 2 550 в тесте. Словарь и TF-IDF построены только по обучающим текстам.

Звёзды приблизительно отражают впечатление автора. Так, в одном отзыве на четыре звезды почти весь текст — жалоба на консультацию. Отзывы на три звезды модель не изучала.

## Запуск

Python 3.13.7, CPU. Установка для macOS и Linux:

```bash
cd clinic-review-classifier
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Для своего отзыва подставьте текст в команду из примера. Чтобы повторить обучение, выполните:

```bash
python -m ipykernel install --prefix "$VIRTUAL_ENV" --name clinic-reviews
python -m nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.kernel_name=clinic-reviews \
  --ExecutePreprocessor.timeout=600 clinic_reviews.ipynb
```

При первом запуске ноутбук скачает около 171 МБ через `curl` и проверит SHA-256. При следующих запусках он прочитает файл из папки `data/`.
